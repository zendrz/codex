# MAYANK AI CODER command playbook

These are prompt playbooks for consistent agent behavior.

- `BUILD.md` — implement and verify.
- `DEBUG.md` — reproduce, isolate, patch, verify.
- `REVIEW.md` — audit without changing unless requested.
- `RESEARCH.md` — gather repository evidence before implementation.
- `PLAN.md` — produce a file-level implementation plan.

The Codex runtime remains responsible for permissions, sandboxing, tool execution, and model calls.
